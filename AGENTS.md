# Vibecraft

A simple vibe coded Minecraft clone written in HTML/JavaScript rendered in a `<canvas>` element using 3D WebGL context.

## Project overview

The code is located inside the /src directory. `index.html` file is the starting point, this file is loaded into a browser to start the game.

## Formatting

Indentations should be 4 spaces. Write `else {` and `else if {` on their own line. CSS declarations should be on their own line.
